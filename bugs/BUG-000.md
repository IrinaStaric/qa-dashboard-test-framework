# BUG-000 — User session remains active in multiple browsers simultaneously

## Area
Authentication / Session Management

## Environment
- Roles: Admin, Operator
- Browsers: Chrome, Safari
- Environment: Local ( QA )

## Description
A user can log in with the same account in multiple browsers at the same time.  
Logging in from a new browser does **not** invalidate or expire existing sessions.

## Steps to Reproduce
1. Log in to the application in **Chrome**.
2. Open **Safari** (or another browser).
3. Log in using the same user account.
4. Switch back to the first browser.

## Actual Result
- Both browser sessions remain active.
- User can perform actions simultaneously in multiple browsers.

## Expected Result
One of the following should happen (based on security requirements):
- Previous session is invalidated when a new login occurs, **or**
- User is notified about multiple active sessions, **or**
- Sessions are explicitly limited by design and documented.

## Impact
- No control or visibility over concurrent active sessions.
- Not aligned with common security expectations for sensitive dashboards.
