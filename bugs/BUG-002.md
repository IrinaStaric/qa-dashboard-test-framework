# BUG-002 — Password visibility icon works inversely (masked/unmasked logic is reversed)

## Summary
Password visibility toggle icon behaves inversely: the password is visible when the icon indicates hidden state, and masked when the icon indicates visible state.

## Environment
- Affected pages:
  - Login page (/auth)
  - Account settings → Change password
- Browser: Chrome, Safari
- OS: macOS

## Steps to Reproduce
1. Navigate to a page with a password input field
2. Observe the password visibility icon (eye / crossed-eye)
3. Click the icon to toggle password visibility

## Actual Result
- When the icon indicates "password hidden" (crossed eye), the password text is visible
- When the icon indicates "password visible" (eye), the password text is masked

## Expected Result
- Crossed-eye icon should correspond to masked password
- Eye icon should correspond to visible password text

## Screens / Logs
- See attachment(s) in `bugs/attachments/BUG-002/`.

## Impact
This behavior is misleading and may cause user confusion when entering or reviewing sensitive information.
Since the same behavior is observed on different pages with password inputs ( Sign in and Admin Account Settings ), the issue may not be limited to these two pages, and could potentially affect other areas of the application.
