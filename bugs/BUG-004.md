# BUG-004 — Operator user can access Management pages via direct URL

## Description
A user with **Operator** role is able to access **Management** pages by navigating directly to their URLs.  
Although Management links are hidden in the sidebar, direct URL access is not restricted, resulting in a visible Management UI for a non-privileged role.

## Severity
**High**

## Environment
- Affected routes:
  - /managementAssets
  - /managementDevices
  - /managementVulnerabilities
- User role: Operator
- Browser: Chrome, Safari
- OS: macOS

## Preconditions
1. Operator user account exists.
2. User is authenticated with **Operator** role.
3. Management navigation items are not visible in the sidebar.

## Steps to Reproduce
1. Log in as an **Operator** user.
2. Manually enter one of the following URLs in the browser address bar:
   - `/managementAssets`
   - `/managementDevices`
   - `/managementVulnerabilities`
3. Observe the page after navigation.

## Actual Result
- Management page loads successfully.
- Management header and UI elements are visible.
- Operator user can view Management content.

## Expected Result
- Operator user should not be able to access Management pages.
- Access via direct URL should be blocked.
- User should be redirected to:
  - Sign In page **or**
  - Access denied / forbidden page.
- No Management UI or content should be rendered for Operator role.
- Status code 403 is expected for a user with limited rights/permissions.
