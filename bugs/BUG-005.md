# BUG-005 — managementAssets API returns 500 on valid CRUD operations

## Summary
`managementAssets` API endpoints intermittently return **HTTP 500 Internal Server Error** for valid CRUD requests due to incorrect backend query construction and missing input validation.

These failures occur during **Create, Read (search), Update, and Delete** operations and are reproducible via UI, browser fetch, and automated API tests.

---

## Environment
- App: Admin Dashboard
- API: `/api/managementAssets`
- Auth:  (admin user)
- Database: PostgreSQL
- Date observed: 01 Feb 2026

---

## Affected Endpoints
- `table_getRecords`
- `table_getRecord`
- `table_updateRecord`
- `table_deleteRecord`

---

## Steps to Reproduce

### Case 1 — Search causes backend crash
1. Login as Admin
2. Open **Assets** page
3. Enter any text in search field (e.g. `abc`)
4. Observe Network request:
5. Response: **500 Internal Server Error**
