# BUG-006 — Management Assets: Type column sorting (A–Z / Z–A) does not sort records correctly

## Summary
Sorting by the **Type** column on **Management Assets** does not reorder the table correctly when toggling between ascending (A–Z) and descending (Z–A).

## Environment
- App: QA Dashboard (local)
- Page: /managementAssets
- Browser(s): Chromium, WebKit.
- OS: macOS

## Preconditions
- Logged in as **Admin**.
- Management Assets table is populated with multiple asset types (e.g., Solar, Hydropower, Wind Turbine, etc.).

## Steps to Reproduce
1. Navigate to **Management Assets** (`/managementAssets`).
2. Locate the **Type** column header.
3. Click the **sort icon** for Type to apply **ascending** sort (A–Z).
4. Observe the order of values in the Type column for the visible rows.
5. Click the **Type** sort icon again to apply **descending** sort (Z–A).
6. Observe the order again.

## Actual Result
- The records are not sorted by Type in the expected alphabetical order when toggling A–Z / Z–A.
- The ordering appears incorrect.

## Expected Result
- When sorting **A–Z**, Type values should be in ascending alphabetical order.
- When sorting **Z–A**, Type values should be in descending alphabetical order.
- Sorting should be stable and consistent across pagination.
