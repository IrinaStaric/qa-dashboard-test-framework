# BUG-008 — Management Assets filter returns 500 and fails to load records

## Area
Management Assets

## Environment
- Role: Admin
- Page: /managementAssets
- Browser: Chrome / Safari
- Environment: Local ( QA )

## Description
When applying a filter on the Management Assets page, records fail to load and the server returns a **500 Internal Server Error**.  
The UI shows a modal with a technical error message instead of handling the case gracefully.

## Steps to Reproduce
1. Log in as Admin.
2. Open **Management Assets**.
3. Open **Filters**.
4. Apply a filter (including cases where a filter value is empty or cleared).
5. Observe the result.

## Actual Result
- Records are not loaded.
- API call `table_getRecords` returns **500**.
- UI displays **“Cannot load records”** with a backend error message.
- Console shows database error related to invalid input.

## Expected Result
- Filters should handle empty or invalid values safely.
- Backend should return a controlled validation error (4xx) or ignore invalid filter input.
- UI should show a user-friendly message without technical details.
