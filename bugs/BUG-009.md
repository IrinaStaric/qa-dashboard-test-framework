# BUG-009 — Refresh button on Management Assets page does not reload data

## Summary
The Refresh button on the Management Assets page does not refresh or reload the records list. Clicking the button does not trigger visible data updates or  records.

## Environment
- App: QA Dashboard
- URL: http://localhost:5480/managementAssets
- Role: Admin
- Browser: Chrome / Safari
- OS: macOS

## Preconditions
- User is logged in as Admin
- Management Assets page is open
- Records are visible in the table

## Steps to Reproduce
1. Navigate to **Management Assets** page.
2. Observe the current list of assets.
3. Click the **Refresh** icon/button.
4. Observe the table content.

(Optional validation)
5. Add, delete, or update a record in another tab/session.
6. Return to the Management Assets page.
7. Click **Refresh** again.

## Actual Result
- The asset list does not update.
- No visible loading indicator appears.
- Data remains unchanged even if backend data has changed.

## Expected Result
- Clicking **Refresh** should re-fetch data from the backend.
- The table should update to reflect the latest state of assets.
- A loading indicator or visual feedback should be shown during refresh.
