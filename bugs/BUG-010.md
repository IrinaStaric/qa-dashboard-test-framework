# BUG-010 — Export data (CSV/XLSX/JSON) does not produce a file and may show blank/black screen

## Summary
On Management Assets page, using **Export data as → CSV / Excel (XLSX) / JSON** does not download any file. The page becomes blank/black after clicking an export option.

## Environment
- App: QA Dashboard (local)
- URL: http://localhost:5480/managementAssets
- Role: Admin
- Browser:Chrome / Safari
- OS: macOS

## Preconditions
- User is logged in as Admin
- Management Assets page is open and records are visible

## Steps to Reproduce
1. Navigate to **Management Assets**.
2. Click the **Export** icon (download icon).
3. Click **CSV**.
4. Observe result.
5. Repeat for **Excel (XLSX)**.
6. Repeat for **JSON**.

## Actual Result
- No file is downloaded.
- No confirmation/toast is shown.
- In some cases the page refreshes or becomes blank/black after clicking export.

## Expected Result
- Selected export format should trigger a download (CSV/XLSX/JSON) containing the expected dataset (current view or selected rows — whichever is intended).
- If export fails, show a clear error message (no blank screen).

## Impact
Admin cannot export data for reporting/auditing. Blank/black screen behavior also looks like an unhandled front-end error and reduces trust in the management UI.
